# SWYNEX Task 2 — TaskFlow Interactive Web Application

TaskFlow is a responsive task manager built with HTML5, CSS3 and vanilla JavaScript. It was created as a frontend internship project.

## Features
- Create, edit and delete tasks
- Mark tasks as completed or active
- High, medium and low priority labels
- Optional due dates and overdue indicators
- Search tasks by title or description
- Filter by view, status and priority
- Sort by newest, oldest, due date or priority
- Dashboard statistics and completion rate
- List and grid layouts
- Form validation
- LocalStorage persistence (tasks remain after refreshing the browser)
- Responsive desktop and mobile layout
- No build tools or external JavaScript libraries required

## Run locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Add a task and refresh the page to test LocalStorage.

## Notes
This is a frontend demonstration project. Task data is stored locally in the current browser and is not synced to a server or shared between devices.
