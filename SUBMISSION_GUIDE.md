# Task 2 Submission Guide

## 1. Test the project
- Open `index.html` in your browser.
- Add at least two tasks with different priorities.
- Edit one task.
- Mark one task complete.
- Search and filter the tasks.
- Refresh the page and confirm tasks remain saved.
- Resize the browser or use mobile device emulation to check responsiveness.

## 2. Create the GitHub repository
Suggested repository name:
`SWYNEX-Interactive-Web-Application`

Suggested description:
`A responsive interactive task manager built with HTML, CSS and JavaScript, featuring task management, search, filters, validation and LocalStorage.`

Recommended settings:
- Public repository
- Do not initialize with another README if you are uploading this project's README
- Add the files from this folder to the repository

## 3. LinkedIn post
Share a short explanation of what you built, what you learned, and include genuine screenshots or a short screen recording of the working app. Mention `@SWYNEX Technologies` and use relevant hashtags such as `#SWYNEX` and `#Internship`.

## 4. Submit
- Task submission link: your GitHub repository URL
- LinkedIn explanation post link: the URL of your published LinkedIn post

Before submitting, open both links in a private/incognito window to confirm they work without requesting access.
